# py-ctvbx

A lightweight Python library to read and export `.ctvbx` (Version 4) files generated by the CT Viewer application.

## Features
- Load `.ctvbx` files into `numpy` arrays.
- Access embedded project metadata and custom parameters.
- Export volumes to DICOM with proper intensity mapping (Standardized Unsigned 16-bit).
- Minimal dependencies: `numpy`, `pydicom`.

## Installation
```bash
pip install .
```

## Usage

```python
import ctvbx

# Load volume
vol = ctvbx.load_volume("sample.ctvbx")

# Access data
print(vol.data.shape)  # (Depth, Height, Width)
print(vol.voxel_size)

# Access metadata
print(vol.window_center)
print(vol.window_width)

# Access custom project parameters
print(vol.get_parameter("ProjectName"))

# Export to DICOM
vol.export_dicom("output_dicom_dir")
```

## Requirements
- Python 3.8+
- numpy
- pydicom
